# EventEase
EventEase is a centralized college event management platform designed to make event planning and organization easier and more efficient. It brings various event-related activities into one system, reducing the need for scattered spreadsheets, paperwork, and disconnected communication.

The platform allows users to create and manage events, handle bookings and registrations, submit requests, and track their status. It also includes features such as search and filtering, notifications, and dashboards to help users access important information easily.

EventEase provides role-based access for students, organizers, and administrators, ensuring that each user can access the features relevant to their responsibilities. Administrators can manage requests, monitor activities, and keep track of event operations.

The main objective of EventEase is to simplify event management, reduce manual work, prevent duplicate data, and improve communication. With its organized structure and user-friendly interface, it aims to make managing college events smoother and more convenient.
